住民税 概算計算

＋詳細機能: 均等割の額を自分の自治体に合わせる・内訳を見る

均等割の年額を変える

標準は4,000円(道府県1,000円+市町村3,000円)に森林環境税1,000円を加えた5,000円です。独自の上乗せがある自治体は実際の額を入れてください。

計算の内訳

住民税は前年(1〜12月)の所得に対して翌年度に課されます。ここで出るのは、入力した年収を稼いだ年の翌年6月〜翌々年5月に納める額の概算です。実際の税額は自治体からの通知書でご確認ください。
このツールでわかること

年収と社会保険料、扶養の人数を入れるだけで、来年いくら住民税が来るかの目安がわかります。転職・退職・独立の直後など、収入が大きく変わるときの資金繰りの確認にどうぞ。

使い方

  1. 年収(源泉徴収票の「支払金額」)を入れます。
  2. 1年間に払った社会保険料の合計(源泉徴収票の「社会保険料等の金額」)を入れます。
  3. 配偶者控除の対象になる配偶者と、16歳以上の扶養親族の人数を選ぶと結果が出ます。ボタンは不要です。
  4. お住まいの自治体の均等割が標準と違う場合は「＋詳細機能」で金額を変えてください。

計算方法と根拠

  • 給与所得 = 年収 − 給与所得控除(下表・所得税法第28条第3項)
  • 課税所得金額 = 給与所得 − (基礎控除43万円 + 社会保険料控除 + 配偶者控除33万円 + 扶養控除33万円×人数)。1,000円未満切捨て
  • 所得割(控除前) = 課税所得金額 × 10%(道府県民税4% + 市町村民税6%)
  • 調整控除 = 合計課税所得が200万円以下なら「人的控除額の差の合計」と「課税所得」の少ないほうの5%。200万円超なら「人的控除額の差の合計 −(課税所得 − 200万円)」の5%(5万円を下回る場合は5万円で計算するため最低2,500円)
  • 所得割 = 所得割(控除前) − 調整控除。100円未満切捨て
  • 年税額 = 所得割 + 均等割(標準4,000円 + 森林環境税1,000円)

計算の前提と注意

  • 税率・控除額は2026(令和8)年7月29日時点の現行規定です。給与所得控除は最低保障額が65万円になった改正後の額(令和8年度分以後の個人住民税に対応)を使っています。
  • 収入は給与1か所のみとし、所得控除は基礎控除・社会保険料控除・配偶者控除・扶養控除だけを見ています。生命保険料控除・医療費控除・iDeCoの掛金などは含みません。
  • 住宅ローン控除・ふるさと納税・配当割額控除などの税額控除は反映していません。これらがある場合、実際の税額はもっと低くなります。
  • 所得税法第28条第4項の「別表第五」(収入660万円未満の速算表)ではなく第3項の算式で計算しているため、実際の額と数百円ずれることがあります。
  • 所得が一定額以下の人は非課税になりますが(限度額は自治体の条例で異なる)、その判定は行っていません。
  • 基礎控除は43万円固定、配偶者控除は33万円固定で計算しています。合計所得金額が2,400万円を超える場合の基礎控除の逓減・消失や、納税者の合計所得が900万円を超える場合の配偶者控除の減額・消失(1,000万円超で適用なし)、合計所得2,500万円超で調整控除が受けられない点は反映していないため、高所得の場合は実際より少なく出ます。
  • 16歳未満の扶養親族には扶養控除がないため、人数に含めないでください。
  • 政令指定都市では内訳(道府県2%+市8%)が変わりますが、合計10%・調整控除の合計5%は同じです。

よくある質問

退職して収入がなくなったのに住民税が来るのはなぜですか?

住民税は前年の所得に対して課される仕組みだからです。前年に働いていれば、今年の収入が0でも前年分の住民税を納めます。退職時は残額を一括徴収されることもあります。

均等割はなぜ5,000円なのですか?

均等割の標準税率が道府県民税1,000円+市町村民税3,000円の合計4,000円で、2024(令和6)年度から森林環境税(国税)1,000円が住民税均等割と併せて徴収されるためです。自治体独自の上乗せがある場合は「＋詳細機能」で金額を変えてください。

調整控除とは何ですか?

所得税と住民税では、基礎控除や扶養控除などの「人的控除」の額が違います(住民税のほうが小さい)。その差で住民税の負担が増えすぎないよう、所得割から差し引く控除が調整控除です。合計所得金額が2,500万円を超える人は対象外です。
