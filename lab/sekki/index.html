二十四節気・雑節 計算

＋詳細機能: 節気ひとつだけを調べる

節気を選んで日付と時刻を見る

上で入れた年の、選んだ節気の日付と時刻(日本標準時)を表示します。

国立天文台が毎年2月に発表する暦要項が正式な日付です。このツールは同じ定義(定気法)で計算していますが、時刻は最大1分程度ずれることがあります。1900〜2100年の範囲で計算し、2021〜2027年の暦要項とは日付がすべて一致することを確認しています。
このツールでわかること

その年の立春・夏至・冬至などの二十四節気と、節分・土用・彼岸・八十八夜・二百十日といった雑節の日付がまとめてわかります。季節行事や販促カレンダーの日付確認にどうぞ。

使い方

  1. 西暦年を入れると、その年の一覧がその場で表示されます。ボタンは不要です。
  2. 「表示するもの」で二十四節気だけ・雑節だけに絞り込めます。
  3. 特定の節気の時刻まで見たいときは「＋詳細機能」を開いてください。

計算方法と根拠

二十四節気は、太陽の視黄経(地球から見た太陽の黄道上の位置)が15度の倍数になる瞬間で決まります(定気法)。その瞬間を日本標準時(UTC+9)に直した日付が、その節気の日です。

  • 春分 = 視黄経0度 / 夏至 = 90度 / 秋分 = 180度 / 冬至 = 270度
  • 立春 = 315度 / 立夏 = 45度 / 立秋 = 135度 / 立冬 = 225度
  • 節分 = 立春の前日
  • 彼岸 = 春分・秋分を中日とする7日間(入りは中日の3日前)
  • 土用入り = 視黄経が 27度(春) / 117度(夏) / 207度(秋) / 297度(冬)になる日
  • 八十八夜 = 立春の日を1日目として88日目
  • 二百十日 = 立春の日を1日目として210日目 / 二百二十日 = 同じく220日目
  • 入梅 = 視黄経80度 / 半夏生 = 視黄経100度

太陽の位置は、Jean Meeus 著 Astronomical Algorithms(第2版)に載っている VSOP87 の切り詰め版に、FK5補正・章動・光行差を加えて求めています。

計算の前提と注意

  • 公式の日付は国立天文台が毎年2月1日に官報で発表する暦要項です。翌年分より先の年は、この計算値も暦要項も予測になります。
  • 時刻は最大1分程度の誤差が出ることがあります。節気の瞬間が0時前後の年は、まれに日付が1日ずれる可能性があります。
  • 雑節のうち社日(春分・秋分に最も近い戊の日)はこのツールでは扱っていません。
  • 二百二十日は暦要項には掲載されていない伝統的な雑節です(立春から220日目として計算しています)。
  • すべて日本標準時(UTC+9)での日付です。
  • 1900年より前・2100年より後は精度を保証できないため計算しません。

よくある質問

節分はいつも2月3日ではないのですか?

違います。節分は立春の前日なので、立春が2月3日になる年(2021年・2025年など)は節分が2月2日になります。逆に立春が2月5日になる年は節分が2月4日です。

「土用の丑の日」はこのツールで出ますか?

土用入りの日は表示しますが、丑の日そのものは表示しません。夏の土用(立秋の前18日間)の中で十二支が「丑」にあたる日が土用の丑の日です。

彼岸は何日間ですか?

春分・秋分を中日とする7日間です。中日の3日前が「彼岸入り」、3日後が「彼岸明け」になります。国立天文台の暦要項に載っているのは彼岸入りの日付です。
