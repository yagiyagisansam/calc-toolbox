基準日を変えると、その日から見た残り日数がわかります。

期限を過ぎても届出はできますが、戸籍法第137条により5万円以下の過料に処せられることがあります。期限の末日が土日祝日にあたるときの取扱いは窓口により異なるため、余裕をもって手続きしてください。
このツールでわかること

出産や身内の不幸のあと、いつまでにどの届出を出せばよいかを日付で確認できます。届出ごとに「初日を数えるかどうか」が法律で違うため、数え間違いを防げます。

使い方

  1. 届出の種類を選びます。
  2. 発生日(出生日・死亡を知った日・転入した日など)を選びます。
  3. 選んだ瞬間に期限日と根拠の条文が表示されます。

計算方法と根拠

  • 出生届 = 14日以内(国外での出生は3か月以内)。戸籍法第49条
  • 死亡届 = 死亡の事実を知った日から7日以内(国外は3か月以内)。戸籍法第86条
  • 転入届・転居届・世帯変更届 = 14日以内。住民基本台帳法第22条・第23条・第25条
  • 転出届 = あらかじめ(日数の定めなし)。住民基本台帳法第24条
  • 婚姻届・離婚届 = 期限の定めなし(届出によって効力が生じる)。戸籍法第74条・第76条
  • 相続放棄・限定承認 = 自己のために相続の開始があったことを知った時から3か月以内。民法第915条
  • 初日の数え方(戸籍法) = 届出期間は届出事件発生の日から起算する(初日を算入)。戸籍法第43条
  • 初日の数え方(住民基本台帳法・民法) = 期間の初日は算入しない(翌日から数える)。民法第140条
  • 「か月」の数え方 = 起算日の応当日の前日に満了。応当する日がない月はその月の末日に満了。民法第143条第2項

計算の前提と注意

  • 法令は2026年7月時点で施行されている条文に基づきます。
  • 出生届・死亡届は戸籍法第43条により初日を算入します(出生日が1日目)。転入届などは民法第140条により翌日から数えます。
  • 民法第142条は「末日が休日で、その日に取引をしない慣習がある場合に限り」翌日に満了すると定めています。戸籍の届出は休日・夜間でも受け付ける窓口がある一方、住民異動届は開庁日のみのことが多く、取扱いが異なります。ここでは一律に翌日へずらしていません。
  • 死亡届の起算日は「死亡した日」ではなく「死亡の事実を知った日」です。
  • 相続放棄の3か月は、家庭裁判所への申立てにより伸長できる場合があります(民法第915条ただし書)。
  • ここに出てくるのは代表的な届出だけです。年金・健康保険・雇用保険などの手続きには別の期限があります。
  • 個別の事情によって扱いが変わることがあります。実際の手続きは市区町村の窓口や専門家にご確認ください。

よくある質問

出生届は「生まれた日を1日目」で数えるのですか?

はい。戸籍法第43条が「届出期間は、届出事件発生の日からこれを起算する」と定めているため、出生日を1日目として14日以内です。7月1日生まれなら7月14日が期限になります。

転入届も引っ越した日を1日目で数えますか?

住民基本台帳法には初日算入の特則がないため、民法第140条により翌日から数えます。7月1日に転入したなら7月15日が期限です。ただし自治体の案内では「引っ越した日から14日以内」と書かれることが多いので、早めに手続きするのが安全です。

期限を過ぎたらどうなりますか?

届出自体は受理されますが、戸籍法第137条により5万円以下の過料に処せられることがあります。遅れた理由を書いた書面を求められる場合もあります。

婚姻届に期限はありますか?

ありません。婚姻は届出によって効力が生じるため、提出した日が婚姻の日になります。「いつまでに出す」という期限の定めはありません。
