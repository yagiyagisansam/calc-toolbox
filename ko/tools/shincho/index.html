키 피트·인치 변환

＋상세 기능: 앞뒤 5cm 조견표, 피트별 조견표

±5cm 피트·인치 조견표

입력한 키를 중심으로 앞뒤 5cm(1cm 간격)의 변환표를 만듭니다.

피트별 인치 0〜11 조견표

「5'9"는 몇 cm?」처럼 해외 키 표기를 연달아 확인할 때는 피트를 하나 고르면 인치 0〜11의 cm 환산을 한눈에 볼 수 있습니다.

이 도구로 알 수 있는 것

cm로 표시된 키가 미국 등 해외에서 자주 쓰는 「5피트 7인치」 같은 표현으로 얼마가 되는지 바로 알 수 있는 도구입니다. 피트·인치에서 cm로의 역변환도 가능합니다. 해외 SNS 프로필을 읽을 때나 영어로 키를 물어볼 때 활용해 보세요.

사용 방법

  1. 변환 방향을 선택합니다.
  2. 키(cm) 또는 피트·인치를 입력합니다.
  3. 입력하는 순간 결과가 자동으로 표시됩니다.

계산 방법과 근거

  • 1인치 = 2.54cm, 1피트 = 12인치 = 30.48cm(정의값)
  • 계산 예: 170cm ÷ 2.54 = 66.93인치 = 5피트+6.93인치 → 표기는 반올림하여 5'7″
  • 「'」가 피트, 「″」가 인치 기호입니다.

출처(1차 정보)

  • 국제 인치의 정의값(1인치=2.54cm)에 기반한 산술 계산입니다.

전제와 주의사항

  • 피트·인치 표기는 인치를 반올림한 「부르는 방식」이므로 ±1cm 정도의 폭이 있습니다(5'7″는 약 168.9〜171.5cm).

자주 묻는 질문

170cm는 미국에서 뭐라고 하면 되나요?

「five seven(5피트 7)」이라고 하면 통합니다. 정확히는 66.93인치이며, 반올림하면 5'7″입니다.

6피트는 몇 cm인가요?

182.88cm입니다. 영어권에서 「6피트」는 장신의 기준으로 자주 쓰이는 표현입니다.

몸무게의 파운드 변환도 되나요?

이 페이지는 키만 변환합니다. 참고로 1파운드는 정의값으로 0.45359237kg이며, 1kg은 약 2.2파운드입니다.
