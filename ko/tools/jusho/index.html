영문식 주소를 일본식으로 되읽기

영문 주소는 「좁은 범위 → 넓은 범위」, 일본식은 「넓은 범위 → 좁은 범위」입니다. 영문 표기를 뒤에서부터 읽으면 일본식 순서가 됩니다.

순서 대조
영문식(앞에서부터)일본식(앞에서부터)
건물·호실 → 번지 → 정역 → 시구정촌 → 도도부현 → 우편번호 → 국가명우편번호 → 도도부현 → 시구정촌 → 정역 → 번지 → 건물·호실
로마자는 일본우편 우편번호 데이터의 가나 읽기를 자동 변환한 것입니다. 실제 지역의 읽는 법과 다르면 로마자 칸을 직접 고쳐 주세요(결과에 바로 반영됩니다).
이 도구로 할 수 있는 것

일본 주소를 영문 표기(로마자·해외식 순서)로 바꿔 주는 도구입니다. 반대로, 로마자로 쓴 일본 주소를 일본어 표기(〒+한자)로 되돌릴 수도 있습니다. 해외 쇼핑몰의 배송지 등록이나 국제우편의 주소 기재는 물론, 구청이나 병원 서류에 일본어로 주소를 적어야 할 때 사용해 보세요.

사용 방법

  1. 「변환 방향」을 선택합니다. 일본어 주소를 영문으로 바꾸려면 일본 주소 → 영문 표기, 로마자 주소를 일본어로 되돌리려면 모국 방식 주소 → 일본어 표기입니다.
  2. 영문 표기로 바꿀 때: 우편번호(예: 100-0014)를 입력하면 주소와 로마자가 자동으로 채워지므로, 번지와 건물명을 덧붙입니다.
  3. 일본어 표기로 되돌릴 때: 거주하시는 나라를 고르고, 평소 쓰던 방식 그대로 주소를 붙여넣습니다. 나라마다 순서가 달라도 읽어 냅니다.
  4. 결과는 바로 아래에 표시됩니다. 복사 버튼을 누르면 그대로 붙여넣을 수 있습니다.

변환 방법과 근거

  • 영문 표기의 순서: 「건물·호실 → 번지 정역 → 시구정촌 → 도도부현 우편번호 → JAPAN」 순서(일본어와 반대)이며, 일본우편의 국제우편 주소 기재 안내를 따릅니다.
  • 주소와 읽는 법: 일본우편의 우편번호 데이터(전국 약 12만 건)에서 해당 우편번호의 주소와 가나 읽기를 가져와 헵번식 로마자로 변환합니다.
  • 정령지정도시는 「구, 시」 순서(예: Chuo-ku, Sapporo), 군 지역은 「정·촌, 군」 순서(예: Yoichi-cho, Yoichi-gun)로 표기합니다.
  • 일본어 표기로 되돌릴 때는 순서가 아니라 형태로 읽어 냅니다. 7자리 숫자는 우편번호, 숫자와 하이픈으로 이루어진 덩어리(3-2-1)는 번지, 나머지는 건물명·호실로 잡고, 우편번호에서 도도부현·시구정촌·정역의 한자를 찾아냅니다. 그래서 큰 단위부터 썼든 작은 단위부터 썼든 결과는 같습니다.

변환의 전제와 주의사항

  • 로마자는 자동 변환이므로 고유한 읽는 법(예: 읽기 어려운 지명)과 다를 수 있습니다. 로마자 칸에서 직접 수정할 수 있습니다.
  • 교토시의 거리 이름 주소(「〜通上ル」 등)나 대형 사업소 전용 우편번호는 정역(町域)이 채워지지 않을 수 있습니다. 그때는 정역 로마자 칸에 직접 입력해 주세요.
  • 주소의 영문 표기에 법적으로 정해진 유일한 정답은 없습니다. 이 도구는 일본우편의 안내에 따른 일반적인 표기를 출력합니다.
  • 일본어 표기로 되돌릴 때 건물명은 로마자 그대로 남습니다. 건물명은 고유명사여서 올바른 일본어 표기를 우편번호만으로는 알 수 없기 때문입니다. 맨션 이름을 아신다면 직접 고쳐 주세요.

자주 묻는 질문

영문에서는 왜 주소 순서가 반대인가요?

영어권에서는 「좁은 범위 → 넓은 범위」 순으로 쓰는 관습이 있기 때문입니다. 일본식(넓은 범위 → 좁은 범위)을 그대로 뒤집으면 영문식이 됩니다.

우편번호를 모를 때는 어떻게 하나요?

「모국 방식 주소 → 일본어 표기」에서 우편번호를 찾지 못했을 때는, 동네 이름의 로마자(예: Nishishinjuku)로 후보를 찾을 수 있는 칸이 나타납니다. 같은 동네 이름이 전국에 여러 곳 있으면 후보 중에서 골라 주세요.

해외에서 일본으로 보낼 때 주소는 반드시 영문이어야 하나요?

국가명(JAPAN)은 보내는 나라에서 알아볼 수 있게 적어야 하지만, 일본 국내 부분은 일본어로 적어도 배달됩니다(일본우편 안내). 영문 표기는 상대가 일본어를 못 쓰거나 해외 사이트의 입력란이 알파벳만 받을 때 편리합니다.

「1-2-3」에서 어디까지가 丁目(초메)인가요?

앞에서부터 「丁目-番地-号」 순서입니다(예: 1-2-3 = 1丁目2番3号). 영문 표기에서도 이 숫자 배열을 그대로 쓰는 것이 일반적입니다.
