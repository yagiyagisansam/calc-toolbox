조건을 정해 한꺼번에 생성

길이와 문자 종류는 위 폼의 설정을 사용합니다. 「헷갈리는 문자 제외」를 선택하면 l(엘)과 1, O(오)와 0처럼 잘못 보기 쉬운 문자가 들어가지 않습니다.

쓰고 있는 비밀번호의 강도 확인

문자 종류와 길이로부터 추측되기 어려운 정도를 개략적으로 계산합니다(입력한 내용은 기기 안에서만 처리되며 어디에도 전송·저장되지 않습니다).

이 도구로 할 수 있는 것

버튼을 누르기만 하면 추측되기 어려운 랜덤 비밀번호를 그 자리에서 만들 수 있습니다. 생성은 모두 사용 중인 기기 안에서만 이루어지며 어디에도 전송되지 않습니다. 새 서비스에 가입하거나 비밀번호를 다시 만들 때 사용해 보세요.

사용 방법

  1. 슬라이더로 길이를 고릅니다(권장: 12자 이상, 중요한 계정은 16자 이상).
  2. 사용할 문자 종류에 체크합니다(사이트의 제한에 맞게 조정).
  3. 페이지를 연 시점에 이미 1개가 생성되어 있습니다. 「복사」로 사용하거나 「다른 비밀번호 생성하기」로 몇 번이든 다시 만들 수 있습니다.

계산 방법과 근거

  • 난수는 브라우저 표준의 암호학적 난수 생성기(crypto.getRandomValues)를 사용합니다.
  • 선택한 문자 종류에서 각각 반드시 1자 이상을 포함한 뒤, 전체를 무작위로 섞습니다.
  • 강도의 기준(비트) = 길이 × log₂(사용 가능한 문자 수). 80비트 이상이면 당분간 안전하다고 보며, 16자에 모든 문자 종류를 쓰면 105비트입니다.

출처·전제

  • 강도(정보 엔트로피)의 개념은 IPA(일본 정보처리추진기구)의 비밀번호 해설(일본어) 등에서 쓰이는 일반적인 지표입니다.

계산의 전제와 주의

  • 생성한 비밀번호를 여러 서비스에서 돌려쓰지 마세요.
  • 보관에는 비밀번호 관리 앱(또는 브라우저의 저장 기능) 사용을 권장합니다.
  • 서비스에서 사용할 수 없는 기호가 있으면 기호 체크를 해제하거나 다시 생성해 주세요.

자주 묻는 질문

생성한 비밀번호가 어딘가에 저장·전송되나요?

아닙니다. 생성은 사용 중인 기기의 브라우저 안에서만 끝나며, 이 사이트의 서버를 포함해 어디에도 전송·저장되지 않습니다. 페이지를 닫으면 사라지므로 필요하면 복사해서 안전한 곳에 보관해 주세요.

몇 자면 안전한가요?

일반적으로 영문 대·소문자와 숫자, 기호를 섞어 12자 이상이 기준이며, 메일·금융 등 중요한 계정은 16자 이상을 권장합니다. 길이를 늘리는 것이 가장 효과적입니다.

외우기 쉬운 비밀번호가 낫지 않나요?

사람이 생각한 비밀번호는 추측되기 쉬운 경향이 있습니다. 랜덤 생성 + 비밀번호 관리 앱 보관이 현재의 정석입니다. 꼭 외워야 한다면 관계없는 단어를 4개 이상 이어 붙이는 방식(패스프레이즈)도 유효합니다.
