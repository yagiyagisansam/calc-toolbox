这个工具能做什么

只需输入年龄和安静心率,就能知道最适合燃脂的心率。按运动辛苦程度(强度)逐级列出目标心率。想知道步行或健身车「该练到什么程度」时就用它。

使用方法

  1. 输入年龄。
  2. 输入安静心率(早晨醒来后、起床前数1分钟手腕脉搏最准确)。
  3. 输入的同时,强度40〜70%的目标心率区间自动显示。

计算方法与依据

  • 最大心率的估算 = 220 − 年龄(广泛使用的估算式)
  • 目标心率 = (最大心率 − 安静心率) × 强度% + 安静心率(卡沃宁公式)
  • 计算例: 40岁·安静心率70的人在50%强度时 → (180−70)×0.5+70 = 125次/分
  • 强度参考: 40〜60%=促进健康·燃脂(轻松〜稍吃力) / 60〜70%=提升耐力(稍吃力)

出处(一次信息)

  • 卡沃宁公式与运动强度的说明: 日本厚生劳动省 e-健康网(身体活动·运动)(日文)

前提与注意

  • 「220−年龄」是估算式,实际最大心率存在个体差异(±10次以上)。
  • 正在治疗心脏病·高血压等疾病,或在服用影响心率的药物(β受体阻滞剂等)的人,请务必咨询医生后再决定运动强度。
  • 运动中若感到胸痛·严重气喘·头晕,请立即停止。

常见问题

听说「轻松的运动」更利于燃脂,是真的吗?

强度40〜60%的运动中,脂肪作为能量被消耗的比例较高,而且容易坚持。不过总消耗热量随强度提高而增加,所以基本原则是「以能坚持的强度,练得更久」。

不知道自己的安静心率。

早晨醒来、起床之前,用另一只手的手指按在手腕拇指一侧数1分钟。也可以用智能手表的睡眠心率代替。成人的大致范围是60〜80次/分。

运动中的心率怎么测?

智能手表或胸带式心率计很方便。没有设备时,也可以暂停运动,数10秒脉搏再乘以6。
