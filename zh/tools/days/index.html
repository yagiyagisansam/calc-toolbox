天数计算器(日期间隔·○天后)

选择开始日和结束日后,天数会立即显示在下方
「100天后是几月几号?」用这里(往前用负数)
＋更多功能: 周数·月数的换算和○个月后的日期

按周数·月数换算

把上面「开始日」「结束日」的差,同时按「周数+零头天数」和「大约几个月」显示(包含首日的数法与住院天数等的算法相同)。

○个月后(○个月前)的日期

从上面的「基准日」起,计算指定月数之后(负数为之前)的日期和星期。

天数有两种数法: 「不含首日(经过天数)」和「包含首日(含两端的天数)」。本工具两种都显示。合同、法律上的期间计算可能另有规定,请注意。
这个工具能做什么

输入两个日期,立即知道相隔多少天。也能计算「100天后是几月几号?」这类未来日期。适合数活动倒计时、办理文件时的期间计算。

使用方法

  1. 天数计算: 选择开始日和结束日,选好的瞬间就会显示间隔天数,无需按钮。
  2. ○天后的计算: 选择基准日并输入天数(过去用负数),对应的日期和星期会自动显示。

计算方法与依据

  • 基于格里高利历(现行公历),将日期转换为连续日数后计算差值与加减。支持闰年(每4年1次;能被100整除但不能被400整除的年份为平年)。
  • 经过天数不含首日(7月18日→7月19日为「1天」)。含两端的天数是在此基础上加1。
  • 计算示例: 2026-07-18 → 2026-08-01 为 14天(含两端为15天)

出处与前提

  • 基于格里高利历(闰年规则)的算术计算。
  • 不考虑节假日和工作日(按日历日计算)。

计算的前提与注意

  • 如需按「工作日」计算(扣除周六日和节假日),请从本工具的结果中减去休息日天数。
  • 法律上的期间计算(如日本民法的首日不算入原则)以具体规定为准。重要期限请查阅相关依据。

常见问题

「○天后」包含当天吗?

不包含。「7月18日的1天后」是7月19日。如果想把当天算作第1天,请把输入的天数减1。

能计算几个月后·几年后吗?

本工具专门计算天数。每个月的天数(28〜31天)各不相同,请先换算成天数再输入(参考: 1个月≒30天、1年=365或366天)。

可以用于过去的日期吗?

支持1600年到2500年。天数输入负数即可计算「○天前」的日期。
