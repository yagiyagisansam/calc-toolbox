日本工作日计算器(排除周末·日本节假日)

选好数值后,结果立即显示在下方
＋更多功能: 反映公司休业日·周六上班

填入公司自己的休息日(如夏季休假),或切换成周六也上班,就会按公司日历重新做同样的计算。

计算时排除周末和日本的法定节假日(含振替休日·国民休日)。不含年末年初、盂兰盆等公司自定休业日。支持范围为2026年1月〜2027年12月。
这个工具能做什么

输入起算日,立即算出「3个工作日后是哪天」——已自动排除周末和日本的法定节假日。日本的节假日和中国不一样(没有春节、国庆长假,却有「黄金周」等日本特有的连休),在日本核对交货期、付款期限,或推算银行、政府窗口哪天恢复办公时,用它就不会数错。也能统计期间内共有多少个工作日。

使用方法

  1. 选择「N个工作日后的日期」或「期间内的工作日数」。
  2. 输入起算日和工作日数(或结束日)。
  3. 输入的瞬间就会显示结果,无需点击按钮。

计算方法与依据

  • 工作日 = 周六、周日、日本节假日以外的日子。
  • 「N个工作日后」从起算日的第二天开始数(周五的3个工作日后=下周三)。
  • 节假日包含振替休日(节假日逢周日时,之后第一个平日补休)和国民休日(被两个节假日夹住的平日)。2026年,被9月21日敬老日和9月23日秋分日夹住的9月22日就是国民休日。
  • 期间内的工作日数把开始日和结束日都算在内。

出处与前提

  • 节假日依据日本《国民祝日相关法律》,并基于日本内阁府「关于国民的祝日」(日文)公布的2026年·2027年一览。

计算前提与注意

  • 银行转账、证券交割等在此之外还有年末年初(12/31〜1/3)等机构自定休业日。准确期限请向各机构确认。
  • 有的公司对工作日的定义不同(周六营业、平日休息等)。
  • 节假日可能因法律修订而变化(支持范围: 2026〜2027年)。

常见问题

「3个工作日以内」包含当天吗?

按惯例多从起算日(提出请求当天)的下一个工作日开始数,但合同或条款可能另有定义。本工具按次日起算计算。重要期限最好向对方确认。

银行的「按下一个工作日处理」是什么意思?

指在周末、节假日或15点以后操作转账时,实际处理会推到下一个工作日。周五15点以后的转账按周一处理(周一是节假日则推到周二)。

节假日数据是什么时候的?

使用日本内阁府公布的2026年·2027年节假日(含振替休日)。超出范围的日期会报错。
