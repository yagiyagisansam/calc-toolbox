电视·显示器的实际尺寸与观看距离

从「○英寸」(即对角线长度)算出实际的宽·高(cm),以及舒适观看距离的参考值(全高清: 高度×3,4K: 高度×1.5)。

换机前后的尺寸对比

用上面选择的屏幕比例,把「从24英寸换到27英寸能大多少?」变成具体数字。

电视·显示器的「◯英寸」指的是屏幕对角线的长度,不是宽度,请注意(例: 65英寸=对角线约165cm,宽度约144cm)。
这个工具能做什么

只要输入数字,就能立即把英寸换成cm(或把cm换成英寸),也可以换算磅和kg。日本日常生活使用公制,但电视和显示器仍按英寸标示,因此在日本买家电、海淘衣服、或看到以磅标示的体重时都很方便。

使用方法

  1. 输入想换算的数值,并选择该数值的单位。
  2. 输入的同时,两种单位的数值立即显示在下方,无需点击按钮。

计算方法与依据

  • 1英寸 = 2.54cm(国际英寸的定义值,换算没有误差)
  • 1磅 = 0.45359237kg(国际磅的定义值)
  • 两者均为1959年英码·磅国际协定的定义值。结果显示到小数点后2位。

前提与注意

  • 鞋·衣服的尺码标注(US·UK尺码等)并不是英寸本身,而是各国的标准。请确认厂商的尺码表。
  • 贵金属使用的「金衡盎司·金衡磅」与常衡磅是不同的单位,本工具不予处理。

常见问题

65英寸的电视宽度是多少cm?

65英寸的对角线约165.1cm,若为16:9的屏幕,宽度约144cm、高度约81cm(不含边框)。确认摆放位置时请以厂商的外形尺寸为准。

可以换算英尺吗?

1英尺=12英寸,把英尺乘以12后按英寸输入即可(例: 6英尺=72英寸=182.88cm)。

健身房哑铃的「45lb」是多少kg?

约20.4kg。国外的杠铃片以45lb(≈20.4kg)为标准,与日本常见的20kg片略有差异。
