偏差值计算器

＋更多功能: 由偏差值算名次、由名次反推偏差值

两者都是把得分分布近似看作正态分布的近似计算。

某个偏差值大约是前百分之几·第几名?

由名次反推偏差值

由「1200人中第300名」这类结果估算偏差值(考生人数使用上面一栏的值)。

偏差值表示的是在参加同一场考试的群体中的相对位置。群体(考生层)不同,同样的实力偏差值也会不同。不同模拟考试的偏差值不能直接比较。
这个工具能做什么

偏差值(偏差値)是日本升学考试中通用的标准化分数,把成绩换算成平均50、标准差10来表示。只需输入考试得分、平均分、标准差,就能立即算出自己的偏差值。不知道标准差时,把全班的分数列表粘贴进来,就能连平均、标准差和所有人的偏差值一起一次算出。适合核对模拟考试成绩、处理班级成绩。

使用方法

  1. 模拟考试成绩单上有「平均分」「标准差」时,输入到①。
  2. 班级小测验等知道所有人分数时,把分数排列输入到②,即可一次算出所有人的偏差值。

计算方法与依据

  • 偏差值 = 50 + 10 ×(得分 − 平均分)÷ 标准差
  • 由分数列表计算时,平均 = 合计÷人数,标准差 = 与平均之差的平方的平均值的平方根(总体标准差)。
  • 计算例: 平均60分、标准差15的考试中得80分 → 50 + 10×(80−60)÷15 = 偏差值63.3

出处与前提

  • 按统计学的标准定义(偏差值=换算为平均50、标准差10的标准化分数)计算。

前提与注意

  • 由分数列表计算时,把「输入的分数群体」视为总体,使用总体标准差。与样本标准差(除以n−1的方式)相比,结果略有不同。
  • 人数较少的群体(如一个班级)的偏差值波动较大,请仅作参考。

常见问题

偏差值最高(最低)能到多少?

理论上没有上限和下限。在群体中拿到极端高(低)的分数时,也可能出现偏差值超过80或低于20(在满分者很多的考试等场合会发生)。

成绩单上没有标准差。

只有平均分无法计算偏差值。知道所有人分数时请使用②的列表计算;模拟考试请查看主办方的成绩资料。

5科总分的偏差值是各科偏差值的平均吗?

不是。总分的偏差值要由「总分的分布」计算,一般不等于各科偏差值的平均(不过通常比较接近)。
