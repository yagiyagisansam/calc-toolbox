这个工具能做什么

只需选择米的合数,就能知道米的重量、加水量和煮好的饭量。「合」是日本电饭锅量米杯使用的传统单位(1合=180ml≈150g)。也能从「想吃500g米饭」「要煮4人份」反算。煮饭拿不准放多少水时用它就行。

使用方法

  1. 选择要煮的合数(以0.5合为单位)。选好的瞬间就会显示米的重量、水量和煮好的饭量。
  2. 用秤量了袋里剩的米时,可用「由克数反算合数」倒推。

计算方法与依据

  • 1合 = 180ml(日本量米杯1杯。日本传统计量单位1升=约1.8L的1/10)≒ 精白米 约150g
  • 加水量参考 = 每合约200ml(米的容积的1.1〜1.2倍)。用电饭锅时以内胆刻度为准。
  • 煮好的饭约为米重量的2.2倍(1合→约330g米饭)。按1碗150g计约2.2碗。

出处(一次信息)

  • 1合=180ml是源自日本计量法中传统计量单位(升)的容量。重量、加水量和煮好的饭量为日本通行的参考值(因大米品种、新米还是陈米、淘米方式而变化)。

前提与注意

  • 免淘米(无洗米)同样容积装的米更多,水建议稍多一点(每合+10〜20ml)作为参考。
  • 新米水分多,水可稍微少放;陈米则稍微多放,更接近喜欢的口感。
  • 用电饭锅煮时,对准内胆的水位线最可靠。

常见问题

1合够几个人吃?

约合2.2碗,大致是2名成人一餐的量。要带便当或有饭量大的人时,不少家庭按每人1合来煮。

没有量杯时怎么量1合?

用厨房秤量150g最准确。用纸杯(200ml)的话,装到接近9分满约为180ml。

5kg大米是多少合,能吃多少天?

5,000g ÷ 150g = 约33合。每天煮2合的家庭约可吃16天。可用本工具的反算模式确认。
