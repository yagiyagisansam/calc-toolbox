本工具按年换算。发生改元的年份(1912·1926·1989·2019年)里,年号随月日不同而不同,因此会同时显示新旧两个年号。
这个工具能做什么

输入西历年份,立即得到对应的日本年号(如令和8年),可直接抄写到表格上(也支持反向换算)。在日本办理市役所、银行、签证等手续时,表格常要求用日本年号(和历)填写日期,本工具帮你快速换算。

使用方法

  1. 输入西历年份(例: 1980),对应的日本年号立即显示在下方,无需点击按钮。
  2. 要从日本年号查西历时,在第二个表单中选择年号和年份。
  3. 需要查改元年份的准确年号、日本年度或周岁年龄时,请打开「＋更多功能」。

计算方法与依据

以各年号的元年为基准: 西历 = 元年的西历 + 年号年数 − 1。

日本年号与西历对照
年号期间(按年)速算公式
明治1868〜1912年(至明治45年)西历 = 1867 + 明治N年
大正1912〜1926年(至大正15年)西历 = 1911 + 大正N年
昭和1926〜1989年(至昭和64年)西历 = 1925 + 昭和N年
平成1989〜2019年(至平成31年)西历 = 1988 + 平成N年
令和2019年〜西历 = 2018 + 令和N年

前提与注意

  • 改元日期: 明治→大正为1912年7月30日 / 大正→昭和为1926年12月25日 / 昭和→平成为1989年1月8日 / 平成→令和为2019年5月1日。改元年份请按具体月日确认年号。
  • 不支持明治以前的年号(庆应及更早)。

常见问题

令和是从西历哪一年开始的?

从2019年(令和元年)5月1日开始。2019年4月30日以前是平成31年。

在日本的表格上怎么填写出生年份?

用本工具换算后直接抄写即可。例如1995年出生填「平成7年」。年号的第一年写作「元年」,不写「1年」。

出生在改元当年,算哪个年号?

按出生的具体日期判断: 在改元日之前是旧年号,当天及以后是新年号(例: 1989年1月7日及以前为昭和64年,1月8日起为平成元年)。可用「＋更多功能」按月日确认。
