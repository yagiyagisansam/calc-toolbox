这个工具能做什么

可以把日本地址转换成英文写法(罗马字·海外通用的由小到大顺序)。反过来,也能把用罗马字写的日本地址还原成日文写法(〒+汉字)。海外网购登记收货地址、国际邮件的收件人栏,以及在市役所、医院的表格上需要用日文填写住址时,都可以使用。

使用方法

  1. 先选择「转换方向」。要把日文地址转成英文,选日本地址 → 英文写法;要把罗马字地址还原成日文,选母国的写法 → 日文写法。
  2. 转成英文时: 输入邮政编码(例: 100-0014),地址和罗马字会自动填入,再补上丁目·番地·号和楼名即可。
  3. 还原成日文时: 选择您所在的国家,按平时的写法直接粘贴地址。即使各国的书写顺序不同,也能正确识别。
  4. 结果会立即显示在下方。点复制按钮即可直接粘贴。

转换方法与依据

  • 英文写法的顺序: 「楼名·房间 → 番地 町域 → 市区町村 → 都道府县 邮政编码 → JAPAN」(与日语顺序相反),依据日本邮政关于国际邮件地址写法的说明。
  • 地址与读音: 从日本邮政的邮编数据(全国约12万条)中取出该邮编对应的地址和假名读音,再转换为平文式(赫本式)罗马字。
  • 政令指定都市按「区, 市」的顺序(例: Chuo-ku, Sapporo),郡下的町村按「町村, 郡」的顺序(例: Yoichi-cho, Yoichi-gun)书写。
  • 还原成日文写法时,不看顺序,而是按形状识别: 7位数字视为邮政编码,数字和连字符组成的一串(3-2-1)视为番地,其余视为楼名·房间号,再用邮政编码查出都道府县·市区町村·町域的汉字。因此无论是由大到小还是由小到大书写,结果都相同。

转换的前提与注意

  • 罗马字为自动转换,可能与当地固有读法(如难读地名)不同。可在罗马字栏直接修改。
  • 京都市的「通り名」地址(如「〜通上ル」)以及大型企业的专用邮编,可能查不到町域。这时请在町域的罗马字栏手动输入。
  • 日本地址的英文写法在法律上并没有唯一的标准答案。本工具输出的是符合日本邮政说明的常见写法。
  • 还原成日文写法时,楼名仍保持罗马字。因为楼名是专有名词,无法从邮政编码得知其正确的日文写法。如果知道公寓的日文名称,请自行改写。

常见问题

为什么英文地址的顺序是反过来的?

因为英语圈的习惯是按「小范围 → 大范围」书写。把日本式(大→小)整个倒过来排列,就是英文式。

不知道邮政编码时怎么办?

在「母国的写法 → 日文写法」中如果没有找到邮政编码,页面会出现用町名罗马字(例: Nishishinjuku)查找候选的输入栏。全国有多个同名町名时,请从候选中选择。

从国外往日本寄东西时,地址必须写英文吗?

只有国名(JAPAN)需要写成寄出国能看懂的形式,日本国内的部分即使用日语书写也能正常投递(日本邮政的说明)。英文写法适合对方不会写日语,或海外网站的输入栏只能填字母的情况。

「1-2-3」中哪个是丁目?

从前往后依次是「丁目-番地-号」(例: 1-2-3 = 1丁目2番3号)。英文写法中一般也照原样保留这串数字。
