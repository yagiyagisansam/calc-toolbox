利率上升情景(浮动利率的风险检查)

比较利率比现在上升 +0.5% / +1% / +2% 时的每月还款额(贷款金额留空则使用上面的计算结果)。

能买多少钱房子的参考值

按 房产价格 =(贷款金额 + 首付)÷(1 + 杂费率)估算(贷款金额与上面相同·日本的杂费参考值为5〜10%)。

这个工具能算什么

只需输入年收入,就能知道在日本房贷大概能贷到多少钱。同时显示每月还款额。采用日本金融机构使用的还款负担率标准,适合在开始看房前确定预算。

使用方法

  1. 以万日元为单位输入年收入(税前)。
  2. 选择还款负担率(家庭收支不吃力的参考值为20〜25%)。
  3. 输入预计利率和还款期限后,可贷额度会立即显示(无需点击按钮)。

计算方法和依据

  • 每月还款额 = 年收入 × 还款负担率 ÷ 12
  • 可贷额度 = 每月还款额 × {1 −(1+月利率)−还款月数} ÷ 月利率(等额本息的反推·年金现值公式)
  • 计算例: 年收入500万日元·负担率25%·利率1.5%·35年 → 每月约10.4万日元,可贷约3,400万日元
  • 还款负担率是「年度还款额占年收入的比例」。日本的审查中一般以30〜35%为上限,但按实际到手收入考虑时,20〜25%被认为是不吃力的水平。

出处·前提说明

  • 这是按等额本息的标准计算公式(年金现值系数)进行的算术计算。还款负担率的水平可参考住宅金融支援机构(Flat 35)的标准(年收入400万日元以上为35%以下等)(日文)。

计算前提和注意事项

  • 这是参考性的约值。实际获批额度会因工作年限·其他借款·房产·团信·审查利率(审查时使用高于实际执行利率的利率)而变化。
  • 「能借到的额度」和「能轻松还得起的额度」是两回事。请结合教育费·养老资金等家庭整体收支来判断。
  • 浮动利率将来可能上升。建议同时确认利率+1〜2%时的金额。

常见问题

最多能贷到年收入的几倍?

近年的参考水平是「年收入的7〜8倍」,但本质在于每月还款额。利率1.5%·35年·负担率25%时相当于年收入的约6.8倍。比起倍数,用负担率来考虑更稳妥。

首付该怎么考虑?

房产价格 = 可贷额度 + 首付 − 杂费(房产价格的5〜10%)。在本工具的结果上加上能准备的首付、再减去杂费,就是购房预算的参考值。

夫妻共同贷款或收入合并会怎样?

可以用夫妻年收入合计的金额来估算(输入合计年收入)。但一方收入减少时的风险也更大,因此理想状态是仅凭一方收入也能偿还的范围。
