大匙·小匙·量杯换算计算器

＋更多功能: 与食材重量(克)的换算

大匙·小匙 → 克

同样是大匙1,重量因食材而异(水15g·砂糖9g·酱油18g等),因此由匙数和食材计算重量。

克 → 大匙·小匙

把「砂糖30g」这类按克写的食谱,不用秤、改用勺子来量的反向换算。

这个工具能做什么

「大匙3是多少ml?」「50ml是几大匙?」——只需输入数字,就能把日本食谱中的大匙·小匙·量杯·ml的分量互相换算。采用日本量匙·量杯的标准(大匙15ml·小匙5ml·1杯200ml,与中国和美国常见的量杯容量不同)。手边没有量匙量杯、想调整分量时都能用。

使用方法

  1. 输入食谱中的分量(数值)。
  2. 选择其单位(大匙·小匙·量杯·ml)。
  3. 输入的瞬间就会显示所有单位下的量,无需点击按钮。

计算方法与依据

  • 小匙1 = 5ml / 大匙1 = 15ml / 1杯 = 200ml(日本量匙·量杯的规格)
  • 大匙1 = 小匙3匙,1杯 = 大匙13匙+小匙1匙。
  • ml和cc是相同的量(1ml = 1cc)。

出处(一次信息)

  • 基于日本标准计量器具的容量(小匙5ml·大匙15ml·量杯200ml)进行换算。

前提与注意

  • 这是容量的换算。重量(g)因食材密度而异(大匙1装水是15g,油约12g,砂糖(上白糖)约9g,盐约18g)。
  • 海外食谱的1杯不一样(美国约240ml、澳大利亚250ml)。日本电饭锅附带的量米杯是180ml,也是另一回事。

常见问题

大匙1是多少克?

因食材而异。参考值: 水·醋·料酒15g,酱油·味淋约18g,油·黄油约12g,砂糖(上白糖)约9g,盐约18g。本工具按容量(ml)换算。

没有量匙时用什么代替?

矿泉水瓶盖约7.5ml(大匙1/2),咖喱勺约略少于大匙1,可作为参考。做点心等需要精确时,建议使用计量器具。

日本食谱里的「一撮」「少许」是多少?

作为参考,少许(少々)=拇指和食指捏起的量(约小匙1/8),一撮(ひとつまみ)=三根手指捏起的量(约小匙1/5〜1/4)。
