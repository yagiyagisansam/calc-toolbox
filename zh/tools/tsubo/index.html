坪单价的计算

根据房产的价格和面积,计算坪单价和㎡单价。

本工具的换算结果为约值。畳按广告标示基准「1枚=1.62㎡」换算,与实际的畳的尺寸(京间·中京间·江户间·团地间)可能不同。
这个工具能做什么

只需输入一个面积数字,就能立即知道换成坪·平方米(㎡)·畳分别是多少。在日本找房时,广告和户型图上这三个单位混着用(广告写「6畳」,合同上却写㎡),用本工具即可快速换算,对房间大小心里有数。

使用方法

  1. 输入要换算的面积数值(例: 100)。
  2. 选择该数值的单位(㎡·坪·畳)。
  3. 输入的瞬间,三个单位的数值全部显示,无需按钮。

计算方法与依据

  • 1坪 = 400/121㎡ ≒ 3.31㎡(1㎡ ≒ 0.3025坪)
    由1尺=10/33米的定义可得 1坪=(6尺)²=400/121㎡。另外,日本《计量法》不允许在交易和证明中使用尺贯法(坪),坪的标示属于习惯性的参考值。
  • 1畳 = 1.62㎡
    这是日本房产广告标示「◯畳」时的基准(以墙心面积计,每枚畳不少于1.62㎡)。

计算的前提与注意

  • 实际的畳的尺寸因地区和种类而异(京间 约1.82㎡、中京间 约1.66㎡、江户间 约1.55㎡、团地间 约1.45㎡左右)。本工具统一按广告标示基准的1.62㎡换算。
  • 房产的正式面积请以登记簿和图纸(以㎡标示)为准。

常见问题

1坪是几畳?

按广告标示基准(1畳=1.62㎡)换算,1坪≒2.04畳。习惯上记作「1坪≒2枚畳」。

同一个房子,为什么不同资料上的面积不一样?

广告多用以墙体中心线测量的「墙心面积」,登记则多用以墙体内侧测量的「内法面积」,因此同一个房间数值会不同。

为什么「6畳」的房间感觉比想象中小?

实际的畳的尺寸因地区和建筑而异(江户间·团地间比京间小),而且广告只要满足1.62㎡×6=9.72㎡以上的基准,就可以标示为「6畳」。
