＋更多功能: 下载时间和「这个容量能装多少」

下载时间估算

输入文件容量和网速(Mbps),在理论值之外还会给出按实际速度(理论值的70%)估算的现实用时。

这个容量能装多少

用上面表单里输入的容量,估算大约能装多少张照片·多少首歌·多少小时视频。

这个工具能做什么

只要输入容量数值,就能一次看到它在KB·MB·GB·TB各单位下分别是多少。电脑的显示(1024进制)和产品包装的标注(1000进制)数法不同,可以切换对照。适合解开「买的500GB在电脑上只显示465GB」这类疑问。

使用方法

  1. 输入容量数值和单位。
  2. 选择换算方式(拿不准就选1024进制)。
  3. 输入的同时,全部单位的数值立即以表格显示,无需点击按钮。

计算方法与依据

  • 1024进制: 1KB=1024B、1MB=1024KB……。Windows和手机操作系统显示文件大小时使用的方式(严格来说这些单位叫 KiB·MiB)。
  • 1000进制: 1KB=1000B、1GB=10亿B……。基于SI词头的方式,用于HDD·SSD·U盘等产品的容量标注。
  • 计算示例: 标称「500GB」的产品(1000进制)= 500,000,000,000B。操作系统按1024进制显示时约为465.7GB——容量看起来「变少了」,主要就是这两种数法的差异造成的。

出处与前提

  • 基于SI词头(1000倍)和二进制词头(1024倍)定义的算术计算。

前提与注意

  • 实际的存储设备还要占用系统区域,因此可用容量可能比两种数法的差异更少。
  • 流量套餐里的「1GB」通常按1000进制计算。

常见问题

买的500GB固态硬盘在电脑上显示465GB,是次品吗?

不是次品。产品标注用1000进制(500,000,000,000字节),而电脑显示用1024进制,所以同样的容量会显示为约465.7GB。可以用本工具切换两种方式确认。

1GB是多少MB?

按1024进制是1,024MB,按1000进制是1,000MB。实际情况是两种数法会根据场合分别使用。

手机流量里的1GB是哪一种?

运营商的数据流量通常按1000进制计算(1GB=1,000MB)。作为参考,看1小时视频大约消耗0.5〜2GB(取决于画质)。
