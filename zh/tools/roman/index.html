罗马数字转换器

＋更多功能: 批量转换·日期的罗马数字写法

批量转换

用逗号或换行分隔,一次最多转换20个(勾选「钟表表盘写法」时,4写作IIII)。

把日期写成罗马数字

把生日或纪念日写成「MMXXVI・VII・XXIV」这样的罗马数字形式(适合戒指刻字或设计草稿)。

这个工具能做什么

只要输入数字,就能立即知道罗马数字(I·V·X·M等)的写法。反过来,也可以把在钟表表盘或电影片名里看到的罗马数字还原成普通数字。想查年份刻印或作品名的读法时很方便。

使用方法

  1. 选择转换方向。
  2. 输入数字(1〜3999)或罗马数字(例: MMXXVI)。
  3. 输入的瞬间就显示结果,无需点击按钮。

计算方法与依据

  • 基本符号有 I=1, V=5, X=10, L=50, C=100, D=500, M=1000 共7个。
  • 按从大到小排列相加,但小符号出现在大符号正前方时要相减(IV=4, IX=9, XL=40, XC=90, CD=400, CM=900)。
  • 计算例: 1994 = 1000(M) + 900(CM) + 90(XC) + 4(IV) = MCMXCIV
  • 罗马数字→数字的转换会验证是否为标准写法(IIII会报错)。

出处与前提的说明

  • 基于罗马数字的标准写法(减法规则)进行转换。

计算的前提与注意

  • 罗马数字没有0和负数,标准写法能表示的范围是1〜3999。
  • 钟表表盘上传统上有时把4写作IIII,但本工具的主表单使用标准写法(IV)。

常见问题

钟表表盘为什么是「IIII」?

说法不一,一般认为是出于表盘外观的平衡(与对面的VIII对称)和传统习惯。数学上的标准写法是IV。

2026年用罗马数字怎么写?

MMXXVI(两个M=1000、两个X=10、VI=6)。常见于电影片尾的制作年份标注。

4000以上不能表示吗?

标准写法最多到3999(MMMCMXCIX)。再往上有加上划线表示乘1000的方法(V̄=5000),但在一般用途中几乎不使用,所以本工具不支持。
