烤箱应该设成多少度?

输入食谱上的华氏(°F),会显示便于在日本的烤箱上设定的10°C为单位的参考值,以及英国食谱的燃气刻度(gas mark)对应值。

这个工具能做什么

只要输入温度数值,就能立即得到摄氏(°C)、华氏(°F)、开尔文(K)三个数值。想把外国食谱的烤箱温度(°F)或美国的天气预报换算成日本通用的摄氏时,用它最方便。

使用方法

  1. 输入温度数值(小数也可以)。
  2. 选择所输入数值的单位(°C·°F·K)。
  3. 输入的同时,三个单位的数值都会显示在下方,无需点击按钮。

计算方法与依据

  • 华氏(°F)= 摄氏(°C)× 1.8 + 32
  • 开尔文(K)= 摄氏(°C)+ 273.15
  • 计算例: 烤箱的350°F 为(350 − 32)÷ 1.8 = 约177°C
  • 不存在低于绝对零度(−273.15°C = −459.67°F = 0K)的温度,因此会提示错误。

出处·前提说明

  • 摄氏与开尔文的关系(t/°C = T/K − 273.15)依据国际单位制(SI)的定义: 日本产业技术综合研究所 计量标准综合中心「国际单位制(SI)第9版」(日文)
  • 与华氏的换算式(°F = °C × 9/5 + 32)是基于单位定义的算术计算。

计算的前提与注意

  • 显示值四舍五入到小数点后2位。
  • 华氏主要在美国使用。「华氏100度」约为37.8°C,相当于盛夏的气温。

常见问题

华氏350度(烤箱)是摄氏多少度?

约177°C。外国食谱中常见的温度为 325°F≒163°C、350°F≒177°C、375°F≒191°C、400°F≒204°C。用日本的烤箱时,大多对应设定在180°C前后的食谱。

有华氏和摄氏数值相同的温度吗?

有,是−40度。−40°C = −40°F 完全一致。这是因为在换算式 F = 1.8C + 32 中令 F = C 可得 C = −40。

开尔文什么时候用?

是物理·化学计算(如理想气体状态方程)中使用的绝对温度单位。下限为0K(绝对零度)= −273.15°C,没有负值。刻度间隔与摄氏相同。
