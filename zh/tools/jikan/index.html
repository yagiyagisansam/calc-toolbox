时间计算器(合计·时刻之差)

＋更多功能: 考勤卡计算和十进制的逆换算

考勤卡计算(实际工作时间和当天工资)

下班时刻早于上班时刻时按夜班(跨日)处理;填入时薪还能算出当天工资的大致金额。

把十进制小时换回「时:分」

可以确认工资单或Excel里的「7.75小时」到底是几小时几分。

这个工具能做什么

像1:30 + 0:45这样把时间相加,或立即算出开始〜结束的经过时间。日本工资单上常用的十进制表示(如7.75小时)也会同时显示。适合统计上班时间、打工(兼职)工时和作业时间。

使用方法

  1. 选择「时间合计」或「时刻之差」。
  2. 算合计时,把「时:分」每行一个(或用逗号分隔)输入;算差值时,选择开始·结束时刻。
  3. 输入的同时会自动显示合计时间和十进制换算(按按钮也可以)。

计算方法与依据

  • 全部先换算成分钟再计算(1:30 → 90分钟)。
  • 十进制换算 = 合计分钟 ÷ 60(例: 8小时30分 = 510分钟 ÷ 60 = 8.5小时)
  • 时刻之差中,结束早于开始时按跨日勤务(夜班等)+24小时计算。

出处与前提

  • 基于时间单位换算(1小时=60分钟)的算术计算。

计算前提与注意

  • 时刻之差不扣除休息时间。计算劳动时间时请另行扣除休息部分。
  • 工资计算的取整规则(如按15分钟为单位舍去)以工作单位的规定为准。

常见问题

8小时30分不是「8.3小时」吗?

不是。30分钟是0.5小时,所以是8.5小时。「时:分」表示和十进制表示的混淆是工资计算中常见的错误,本工具把两种表示并排显示。

怎样算出扣除1小时休息后的实际工作时间?

先用「时刻之差」算出总在班时间,再从显示的合计里减去1小时(列表中无法输入「-1:00」这样的负数)。例: 9:00〜18:00=9小时 → 实际工作8小时。

能用来合计一个月的加班时间吗?

可以。把每天的加班时间(如0:45)按换行分隔粘贴进来,就能一次得到月合计和十进制换算(工资单常用的格式)。
