日本消费税计算器(含税⇔不含税)

＋更多功能: 多件商品合计与源泉征收(预扣税)

多件商品合计(10%和8%税率混在一起也可以)

按行输入不含税金额,按「每档税率的小计只计一次税」的方式自动合计(日本发票·收据的通行做法)。

源泉征收(预扣税)计算(自由职业者的请款单)

计算稿费·讲课费·设计费等支付给个人的报酬中被预先扣除的源泉征收税(10.21%,超过100万日元的部分为20.42%)和到手金额。

本工具的计算结果为约值。不足1日元的尾数按四舍五入计算,但实际的尾数处理(舍去·进位·四舍五入)因商家而异,可能与店内小票有1日元左右的差异。
这个工具能做什么

只需输入金额,立即算出按日本消费税含税是多少·不含税是多少。同时支持标准税率10%和适用于食品饮料等的轻减税率8%。在日本购物时核对价格、开具请款单时都很方便。

使用方法

  1. 以日元为单位输入整数金额。
  2. 选择「不含税→含税」还是「含税→不含税」。
  3. 选好税率(10%或8%),结果连同税额明细立即显示,无需点击按钮。

计算方法与依据

  • 不含税→含税: 消费税额 = 不含税价 × 税率,含税价 = 不含税价 + 消费税额
  • 含税→不含税: 不含税价 = 含税价 ÷ (1 + 税率),消费税额 = 含税价 − 不含税价
  • 税率为日本消费税的标准税率10%和轻减税率8%(酒类·外出就餐以外的食品饮料,以及每周发行2次以上的订阅报纸),自2019年10月1日起适用。
  • 计算例: 不含税1,980日元(轻减8%)→ 税158日元·含税2,138日元 / 含税1,980日元(10%)→ 不含税1,800日元·税180日元

前提与注意

  • 是否适用轻减税率(8%)按品目·提供方式有细致规定(例: 外带为8%,店内用餐为10%)。准确的区分请查阅日本国税厅的资料。
  • 若税率发生调整,本页所载税率为参照日时点的税率(请确认页面标注的参照日期)。

常见问题

哪些东西适用8%(轻减税率)?

酒类·外出就餐以外的食品饮料,以及每周发行2次以上的订阅报纸。同一件商品,外带是8%,在店内吃则是10%。

计算结果和小票差1日元。

因为不足1日元的尾数处理(舍去·进位·四舍五入)各商家不同。本工具统一按四舍五入计算。

日本价签上的「内税」「外税」是什么意思?

「内税」指标价已含消费税,「外税」指按不含税价格+税另计标示。面向消费者的价格标示原则上应为含税总额。
