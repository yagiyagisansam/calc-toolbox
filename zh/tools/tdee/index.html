根据一天的摄入热量,按日本国家目标量计算蛋白质(P)、脂肪(F)、碳水化合物(C)各应摄入多少克(在上面反算后会自动填入)。

本工具的计算结果为约值。体格、肌肉量、活动内容不同会有个人差异,孕期、哺乳期或患有疾病者不适用。饮食治疗请遵循医生和注册营养师的指导。
这个工具能做什么

只需选择年龄、性别、体重和每天的活动量,就能知道一天可以吃多少热量的参考值。计算采用日本《饮食摄取基准》的思路,即日本营养指导所使用的国家标准。适合在减肥或增肌时制定饮食计划。

使用方法

  1. 输入年龄、性别和体重。
  2. 选择最接近平时活动量的「身体活动水平」。拿不准就选「Ⅱ 普通」。
  3. 输入的同时,一天的摄入热量参考值和基础代谢量立即显示在下方,无需点击按钮。

计算方法与依据

  • 摄入热量参考值(估算能量需要量) = 基础代谢量 × 身体活动水平
  • 基础代谢量 = 基础代谢基准值(按年龄段、男女分列) × 体重(与本站基础代谢量计算相同的方式)
  • 身体活动水平(成人的代表值): Ⅰ 低=1.50 / Ⅱ 普通=1.75 / Ⅲ 高=2.00
  • 计算示例: 30岁男性70kg·普通 → 基础代谢约1,561kcal × 1.75 = 约2,732kcal/日

前提与注意

  • 该数值是「维持现在体重」所需能量的参考值。想减重就比它少吃,想增重就多吃,但极端限制会损害健康。
  • 身体活动水平的代表值为成人数值。高龄者即使同一档,实际水平也往往偏低一些。
  • 未满18岁(生长发育期)适用其他标准,不在本工具适用范围内。

常见问题

想瘦下来的话,应该吃多少kcal?

一般认为,每天比该参考值少摄入200〜500kcal左右可实现平缓减重;但大幅低于所需量的限制会导致肌肉减少和反弹。具体目标请咨询医生或注册营养师。

和基础代谢量有什么区别?

基础代谢量是「即使安静不动也会消耗的最低限度能量」;本工具的结果是在其基础上乘以日常活动量,得出「与一天消耗相当的摄入量参考值」。

身体活动水平该怎么选?

以办公桌工作为主、移动也少选Ⅰ;有通勤、购物、家务或轻度运动选Ⅱ;站立工作或运动习惯活跃选Ⅲ。
