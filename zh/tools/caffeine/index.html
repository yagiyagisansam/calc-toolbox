咖啡因摄入量计算器

输入饮料和量,合计立即显示在下方
＋更多功能: 就寝时残留的咖啡因·最后一杯的时刻

睡觉时还剩多少?

根据喝的时刻·杯数·预定就寝时间,按半衰期约5小时的参考值计算就寝时残留的咖啡因量(1杯150ml≒90mg)。

最晚几点前喝完?

根据上面的杯数和预定就寝时间,反算最后一杯的时刻,使就寝时的残留量低于100mg(容易影响睡眠的参考线)。

这个工具能做什么

只需输入喝了什么和喝了多少,就能知道今天摄入的咖啡因合计,并对照每日参考值(健康成人400mg)确认是否过量。适合常喝咖啡或能量饮料的人自查。

使用方法

  1. 输入喝的饮料(咖啡·茶·能量饮料等)和量(ml)。
  2. 点「+ 添加饮料」可以把一天喝的都加进来。
  3. 输入的同时,合计mg和相对参考值的百分比立即显示在下方。重新选择饮料也会即时重算。

计算方法与依据

  • 咖啡因量 = 浓度(mg/100ml)× 量(ml)÷ 100 的合计
  • 浓度采用日本食品标准成分表(浸出液)等的数值: 咖啡60 / 速溶57 / 红茶30 / 煎茶·焙茶·乌龙茶20 / 玉露160 / 可乐约10 mg/100ml
  • 计算例: 咖啡2杯(400ml)+瓶装绿茶(500ml)= 240+100 = 340mg(成人参考值的85%)
  • 参考值: 健康成人每日不超过400mg(欧洲食品安全局等的评估)。孕期·哺乳期应更少(WHO为300mg,多数机构建议200mg)。

出处与前提

  • 饮料中的咖啡因浓度与摄入参考值: 日本农林水产省「关于咖啡因的过量摄入」(含日本食品安全委员会·海外机构的评估)(日文)

前提与注意

  • 能量饮料的咖啡因含量因产品差异很大(1罐30〜300mg)。准确数值请查看产品标签。
  • 对咖啡因的敏感度个体差异很大,有人少量也会睡不着。
  • 如经常服用咖啡因片·提神饮料,或对身体状况有顾虑,请咨询医生·药剂师。

常见问题

一天最多能喝几杯咖啡?

1杯滴滤咖啡(150ml)约含90mg,健康成人的参考值400mg相当于4〜5杯左右。不过个体差异很大,傍晚以后喝容易影响睡眠,量和时间都要注意。

睡前几小时内不宜喝咖啡?

咖啡因的血中浓度减半约需4小时(2〜8小时,因人而异)。觉得影响睡眠的人,最好在就寝前5〜6小时之前喝完。

孕期应控制在多少以内?

WHO建议每日不超过300mg,英国等多数机构建议不超过200mg。本工具也会显示相对200mg基准的百分比。如有主治医生的指示,请以医嘱为准。
