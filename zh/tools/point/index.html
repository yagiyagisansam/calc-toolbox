这个工具能做什么

「10%OFF」和「10%积分返还」——看起来一样,其实打折稍微更划算。本工具计算两种方案的实际支出并判定哪个更划算。日本的商店和无现金支付常有积分返还活动,在打折价和积分活动之间犹豫时可以用它比一比。

使用方法

  1. 输入商品价格。
  2. 输入要比较的「折扣率」和「积分返还率」(其中一个为0也可以)。
  3. 3项输完的同时,判定结果和实际价格对比表立即显示,无需点击按钮。

计算方法与依据

  • 打折: 支付额 = 价格 × (1 − 折扣率÷100)
  • 积分返还: 实际负担 = 价格 × (1 − 返还率÷100)(前提是获得的积分日后全部用掉)
  • 但积分返还时「实际支付的钱」仍是原价。每100日元返r日元积分,换算成折扣率是 100r ÷ (100 + r) %(10%返还即 1000÷110 = 约9.09%OFF)。同样的数字下打折更划算,原因就在这里。
  • 计算例: 1万日元的商品,「10%OFF」支付9,000日元;「10%返还」支付10,000日元+得1,000积分(实际相当于9,000日元),但换算成折扣只有9.09%,所以10%OFF更划算。

出处·前提说明

  • 算术计算。积分按「1积分=1日元、日后可全额使用」的前提计算。

前提与注意

  • 如果积分有有效期、用途受限或容易失效,实际价值会低于计算值。
  • 很多制度对「用积分支付的部分」不再送积分,这也是返还比打折稍微吃亏的原因之一。
  • 有返还上限(例: 最多2,000积分)的活动,商品越贵实际返还率越低。

常见问题

为什么「10%OFF」和「10%返还」不一样?

10%OFF是花9,000日元买到1万日元的商品。10%返还是付1万日元、得1,000日元积分,相当于「花1万日元买到11,000日元的价值」,换算成折扣率约9.09%。先少付钱的打折总是稍微更划算。

多少返还率才和「20%OFF」打平?

25%返还。把r=25代入换算式 100r÷(100+r),得 2500÷125=20%,正好相当于20%OFF。

反正积分都会用掉,那不是实际一样吗?

如果确定能全部用完,实际负担额确实相同(1万日元·10%时双方都是9,000日元)。但返还是「钱先花出去」,还有失效·忘记使用的风险,这点上不利。本工具同时显示两种视角(实际负担额和折扣换算率)。
