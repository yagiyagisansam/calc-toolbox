# 地図パネル重なり修正レポート（Claude引継ぎ用）

作成日: 2026-08-16

対象リポジトリ: `yagiyagisansam/calc-toolbox`

作業ブランチ: `claude/stargazing-spot-site-uijopc`

## 不具合

地図左上の日時・時刻パネルと、左下の星見レベル／天気凡例が画面条件によって
重なっていました。凡例を移動・退避する操作もなく、下側の地図を確認できませんでした。

## 原因

`stars/stars.css` で日時パネルと凡例の両方を左端基準で絶対配置していました。
横幅640px以下の調整はありましたが、ブラウザ倍率、表示領域の高さ、640pxを超える
中間幅を組み合わせた場合の衝突を避ける設計になっていませんでした。

## 修正

### `stars/stars.css`

- 日時・時刻パネルを右上基準へ変更。
- 641px以上では左側に凡例用310pxを必ず予約し、残りの範囲だけを日時パネルに使用。
- 640px以下では従来どおり日時パネルを左右いっぱいに配置。
- 凡例全体の開閉見出しと「折りたたむ／開く」の表示を追加。

### `stars/index.html`

- 凡例全体を、標準HTMLの `details` / `summary` で折りたためる構造へ変更。
- JavaScript依存のドラッグ操作にはせず、クリック・タップ・キーボードで開閉可能。
- 初期状態は開いたままなので、従来の情報量は維持。

### 回帰検査

`scripts/stars/verify.mjs` と `scripts/stars/verify_live.mjs` に次を追加しました。

1. 日時パネルと凡例の矩形が交差していないこと。
2. 凡例見出しを押すと閉じ、パネル高が小さくなること。
3. もう一度押すと開いて、後続の地図操作を続けられること。

## 検証結果

- 1110×755: パネル重なりなし。
- 768×600: パネル重なりなし。
- 390×844: パネル重なりなし。
- 390×844で凡例を閉じると、高さ229pxから42pxへ縮小。
- `node scripts/run_tests.mjs`: 1301 / 1301件通過。
- `node scripts/stars/check_candidates.mjs`: 973 / 973件通過。
- `node --check scripts/stars/verify.mjs`: 通過。
- `node --check scripts/stars/verify_live.mjs`: 通過。
- `git diff --check`: 問題なし。

座標、掲載スポット、Supabaseデータには変更を加えていません。

## Claudeへの申し送り

- `.stars-topbar` を再び左固定へ戻すと同じ不具合が再発します。
- 凡例をドラッグ可能にする追加実装は不要です。折りたたみは位置を見失わず、タッチ操作と
  キーボード操作にも標準対応するため、今回はこちらを採用しました。
- 今後パネル内の文言や行数を増やす場合も、矩形交差検査を残してください。
