## 2. P1-4 地名の補完を、ID・応答fixture・種別の検証にする

**未着手。** いまの補完辞書（`places-extra.mjs`）は GeoNames の id と日本語名だけを
書き、座標は元データから取る作りになっている。これは「GeoNames に地点はあるが
日本語名が無い」場合にしか効かない。

**GeoNames に地点そのものが無い4語**が残っている。

| 語 | いまの結果 | 何が問題か |
|---|---|---|
| 美ヶ原 | 0件 | 元データに無い |
| 洞爺湖 | 洞爺湖町 | 湖ではなく**自治体**が出る |
| 四国カルスト | 0件 | 元データに無い。掲載候補が2件ある地域なのに引けない |
| 野辺山 | 野辺山（集落） | 高原名ではなく**集落**が出る |

独立検証3の提案（`INDEPENDENT-REVIEW-3.md` の B）は、補完レコードを
`{ name, kana, source, query, expectedTitle, expectedPref, expectedMuniCodes, expectedKind }`
の形にし、ビルド時に国土地理院の地名検索を1回引いて

1. 表示名が完全一致
2. 種別が期待する地形種別と一致（**自治体・集落で代用しない**）
3. 逆ジオコーダの県・市町村が許容集合に入る
4. 生応答・取得日・URL・SHA-256 を fixture に残す
5. 0件または複数件ならビルドを止める

を全部満たしたときだけ採用する、というもの。**この形に作り替える必要がある。**

注意点として独立検証3が挙げているもの:

- 国土地理院「地名集日本」は約4,100件で、この4語は完全一致を確認できなかった。
  これだけを万能な補完元にはできない。
- 公式の機械可読ソースが無い地点だけ Wikidata QID 等を補助元にしてよいが、
  QID・リビジョン・座標claim・SHA-256・公式ページによる照合を残すこと。
  **人が座標を書き写すのではなく、ビルドが取得して検証する。**

`fetch_fixtures.mjs`（JPL Horizons）が既にこの形（問い合わせを記録し、
生応答を gzip で残し、指紋を計算し直せる）になっているので、
そこを下敷きにできる。

## 3. P1-5 日本語の別名を捨てない

**未着手。** GeoNames の別名から表示名を1つ選び、残りを捨てている。
「良い語尾」の候補が2つ以上ある地点が **464/9,755件**あり、
そのうち阿蘇山（「中岳」が選ばれていた）だけを補完辞書で上書きした。
**同じ形の取り違えが他に残っている可能性がある。**

独立検証3の提案:

- 表示名 `canonicalName` と検索用 `aliases[]` を分ける
- 漢字の日本語別名は原則すべて検索対象に残し、同一 GeoNames ID へ束ねる
- 表示名は 公式標準地名 → 完全一致の自治体名 → 補完辞書 の順で選ぶ
- 検索結果は別名ごとではなく**地点IDごとに重複排除**する
- 「別名のどちらを打っても同じ地点IDへ着く」テストを作る

索引の大きさへの影響を測ってから決めること（いまは主 181KB / 集落 446KB）。

## 4. 測っていないこと

- **集落索引（446KB）の iPhone 実機での挙動。** 開発機（Node）では
  JSON.parse 25.8ms / 寄せた形を作る 17.1ms / 検索1回 1.62ms / heap 20.1MB。
  実機の転送時間・parse・入力の反応は測っていない。
  都道府県が選択済みなら県別ファイルを引く構成も、独立検証3が提案している。
- **集落索引に読みが無い。** かな入力で小地名を探せない。

## 5. 直したが、限界が残るもの

- **iframe はセキュリティ境界ではない。** `allow-same-origin` は外せない
  （地図の worker が同一生成元でないと動かない）ので、枠の中が乗っ取られれば
  親の DOM へ直に手が届く。得られているのは「MapLibre の DOM 書き込みを
  親の文書から外した」ことだけ。本当に分けるなら地図を別の生成元から配ることに
  なるが、GitHub Pages の1生成元では取れない。
- **`index.html` だけ Trusted Types が無い。** 画面そのものが地図なので分けられない。
  守れているのは 一覧・詳細・申請・データについて の4画面。
- **座標と市区町村の照合は行政界で見ているが、行政界の多角形は持っていない。**
  国土地理院の逆ジオコーダに1件ずつ聞いた結果を JSON に持っている
  （`cityCheck`）。取り直しは `verify_candidate_cities.mjs`。
