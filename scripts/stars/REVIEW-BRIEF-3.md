# A. 掲載候補17件の座標の取り直し ── 最優先

## A-1. 何が起きたか

前回いただいた「`city` と座標が都道府県境界を含め整合する機械検査」を作るにあたり、
最初は同梱の地名索引（市区町村の**役場の代表点**）からの距離で見ていました。
これは当てになりませんでした。役場は自治体の中心ではないので、
広い自治体では隣町の役場のほうが近いことが普通にあり、
**正しい7件を疑って、本当の誤り1件を見逃していました。**

そこで**国土地理院の逆ジオコーダ**（行政界そのもので答える）に切り替えました。
`scripts/stars/verify_candidate_cities.mjs` が候補47件の座標を1件ずつ問い合わせ、
結果を `spot-candidates.json` の `cityCheck` に書き込みます。

結果は**47件中21件が、記録している市区町村と違う場所に落ちました。**
そのうち1件は**県すら違いました**（福岡県の候補が大分県日田市に落ちる）。

4件は国土地理院の地名検索で正しい座標を取り直せました（下の A-4）。
**残る17件は、私の手元では正しい座標を確定できませんでした。**

いずれも**承認対象から外して「保留」にしてあります**。
判定の内訳は 掲載可 7 / 条件付き可 10 / 保留 26 / 除外 4 です
（座標が確定していない候補を Hiroさんが承認できてしまうと、
違う場所を掲載することになるため、機械の検査でも落とすようにしました）。

## A-2. 調べてほしいこと

17件それぞれについて、**その施設・地点の正しい緯度経度**を確定してください。

判断の材料は2つあります。**どちらが正しいのかを決めてください。**

1. **名前が正しく、座標が間違っている** → 正しい座標を出してください
2. **座標が正しく、市区町村の記載が間違っている** → 正しい市区町村を出してください

県境・市境の上にある地点（四国カルスト、茶臼山高原、二本杉峠など）は、
**どちら側に駐車場があるか**で決まります。名前だけでは決まりません。

### 座標の出どころ（推奨する順）

| | |
|---|---|
| 1 | 施設・自治体の公式ページに載っている緯度経度、または公式の地図 |
| 2 | 国土地理院 地名検索 `https://msearch.gsi.go.jp/address-search/AddressSearch?q=<名前>`（**名前が完全一致したときだけ**信用できます。部分一致は同名の別地点を返します） |
| 3 | 公式の住所 → 国土地理院の住所検索（**大字までしか出ません。誤差は数km**） |

**確定できたら、必ず逆ジオコーダで確かめてください。**

```
https://mreversegeocoder.gsi.go.jp/reverse-geocoder/LonLatToAddress?lat=<緯度>&lon=<経度>
```

返ってきた `muniCd` が、記録している市区町村と一致すること。
市区町村コードの対応表は `https://maps.gsi.go.jp/js/muni.js` です
（逆ジオコーダは5桁 `"01460"`、対応表は先頭の0を落とした `"1460"` で持っています）。

**推測で座標を書かないでください。** 確定できなければ「確定できなかった」と書いてください。

# B. 地名索引の取りこぼし

`stars/data/places.json` は GeoNames の日本データから作っています。
GeoNames は**日本の山のうち 3436/4353 件にしか漢字の別名を持ちません。**
英字名だけの山は、日本語の検索欄しかないこのサイトでは「存在しない」のと同じです。

主要なものは `scripts/stars/places-extra.mjs` で補いました
（槍ヶ岳・妙高山・鳥海山・雲仙岳・阿蘇山・琵琶湖）。
**やり方は「GeoNames の id と日本語名だけを書き、緯度経度・標高は元データから取る」**です。
人が座標を書き写すと検算のしようがないので、そうしています。
id が見つからなければビルドが止まります。

## B-0. 先に直した2つ（点検してください）

取りこぼしを数えるために、利用者が実際に打ちそうな語112件（掲載候補の名前・
市区町村・よく知られた山や高原）で試したところ、**56件が0件**でした。
うち大きな原因が2つあり、どちらも索引の作り方の誤りだったので直しました。

1. **市区町村が「市・町・村」抜きで入っていた。**
   名前を「短いほう」で選ぶ規則のせいで、GeoNames が「宮崎」と「宮崎市」を
   持っていると短いほうだけが索引に入り、**「宮崎市」「青森市」「田村市」と
   打つと0件**になっていました。住所を打つ人は市まで入れます。
   行政区分だけ「正式な形（市/区/町/村/郡で終わる）を優先し、そのうえで長いほう」に変えました。
   「宮崎」でも前方一致で当たるので、失うものはありません。

2. **表記の揺れで0件になっていた。**
   国土地理院の市区町村名1885件と索引を突き合わせて、実際に食い違うものを探しました。
   `ケ`/`ヶ`（金ケ崎町・七ケ宿町・保土ケ谷区 ↔ 茅ヶ崎市）と、
   異体字（諌↔諫、竃↔竈、桧↔檜、條↔条）です。
   比べるときだけ同じ形に寄せるようにしました。

   **`ケ` の扱いに1つ落とし穴があります。** 見境なく `ヶ` へ寄せると、
   カタカナで打った読み「ヤツガタケ」が「やつがたヶ」になって索引と当たりません。
   **漢字に隣接しているときだけ寄せる**ようにしています
   （`茅ケ崎` の `ケ` は箇の略字、`ヤツガタケ` の `ケ` はカタカナの一音）。
   **この線引きで漏れはありませんか。**
