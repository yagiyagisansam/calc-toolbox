Reading an English address back into Japanese order

An English address goes from small to large, a Japanese one from large to small. Read the English version backwards and you get the Japanese order.

The two orders side by side
English order (front to back)Japanese order (front to back)
Building and room → house number → town area → city or ward → prefecture → postal code → countryPostal code → prefecture → city or ward → town area → house number → building and room
The romaji is a machine conversion of the kana readings in Japan Post postal code data. If your area is read differently, simply rewrite the romaji fields (the result updates immediately).
What this tool does

It turns a Japanese address into English (romaji, in the Western small-to-large order). It also works the other way round, turning a Japanese address written in Roman letters back into Japanese (〒 plus kanji). Use it for overseas shopping sites and international mail, and for the moments when a city-hall or hospital form asks you to write your address in Japanese.

How to use

  1. Choose the direction. To turn a Japanese address into English, pick Japanese address → English; to turn a romaji address back into Japanese, pick The way you write it at home → Japanese.
  2. Going into English: type your postal code (for example 100-0014) and the address and its romaji fill in automatically, then add the block and house number and the building name.
  3. Going back into Japanese: choose your country and paste the address exactly the way you normally write it. It is read correctly whichever order your country uses.
  4. The result appears right below. Use the copy button to paste it straight into a form.

How it is converted

  • Order in English: “building and room → house number and town area → city or ward → prefecture and postal code → JAPAN”, the reverse of the Japanese order. This follows Japan Post guidance on addressing international mail.
  • Address and reading: the address and its kana reading for each postal code come from Japan Post postal code data (about 120,000 entries nationwide) and are converted to Hepburn romanization.
  • Designated cities are written as “ward, city” (for example Chuo-ku, Sapporo), and rural districts as “town or village, district” (for example Yoichi-cho, Yoichi-gun).
  • Going back into Japanese, the address is read by shape rather than by order: a group of 7 digits is taken as the postal code, a group of digits and hyphens (3-2-1) as the house number, and whatever is left as the building name and room number. The kanji for the prefecture, city and town area are then looked up from the postal code. That is why the result is the same whether you write from large to small or from small to large.

Assumptions and notes

  • Because the romaji is generated automatically, it can differ from the actual local reading (some place names are read in unusual ways). You can correct it directly in the romaji fields.
  • For Kyoto street-name addresses (“…dori agaru” and similar) and for the individual postal codes of large businesses, the town area may be missing. In that case type it into the town area romaji field yourself.
  • There is no single legally correct way to write a Japanese address in English. This tool produces the common style described by Japan Post.
  • When converting back into Japanese, the building name stays in Roman letters. A building name is a proper noun, and its correct Japanese spelling cannot be derived from the postal code. If you know how your building is written, please replace it yourself.

Frequently asked questions

Why is the order reversed in English?

English-speaking countries write addresses from the smallest unit to the largest, the opposite of Japan. Take the Japanese order (large to small) and reverse it and you have the English one.

What if I do not know my postal code?

When no postal code is found in “The way you write it at home → Japanese”, a field appears where you can search by the town name in Roman letters (for example Nishishinjuku). If the same town name exists in several places in Japan, pick the right one from the candidates.

If someone sends me a parcel from abroad, does the address have to be in English?

Only the country name (JAPAN) has to be readable in the sending country. According to Japan Post, the part inside Japan can be written in Japanese and will still be delivered. The English version is useful when the sender cannot write Japanese or when a website only accepts Roman letters.

In “1-2-3”, which number is the chome?

They run in the order chome-banchi-go from the front (so 1-2-3 means 1丁目2番3号). The same string of numbers is normally kept as is in the English version.
